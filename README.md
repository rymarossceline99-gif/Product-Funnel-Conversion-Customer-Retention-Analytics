# Product Funnel, Conversion & Customer Retention Analytics

## Project Overview

This project analyses e-commerce customer behaviour using Google Analytics 4 sample data. The objective is to understand how users interact with an online store, identify conversion drop-offs, analyse customer retention, and explore purchasing behaviour.

## Dataset

- **Source:** Google Analytics 4 Public Sample Dataset
- **Platform:** Google BigQuery
- **Period:** November 1, 2020 – January 31, 2021
- **Total Events:** 4,295,584
- **Unique Users:** 270,154

## Tools & Technologies

- SQL – Data exploration and analysis
- Google BigQuery – Cloud data warehouse
- Python – Data analysis and visualisation
- Power BI – Interactive dashboard development

## Project Analysis

1. Event Distribution and User Activity
2. Dataset Overview and Data Quality
3. Product Funnel and Conversion Analysis
4. Customer Retention and Cohort Analysis
5. Revenue and Customer Behaviour Analysis
